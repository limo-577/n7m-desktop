# 唱歌笔记桌面版 · N7m Desktop

一款面向唱歌练习的 Windows 桌面应用，将 **歌词标注工具** 与
**本地音乐播放器**
合并在同一个软件中。你可以为歌词添加演唱提示，再播放歌曲进行对照练习；也可以显示桌面悬浮歌词。

## 主要功能

### 📝 歌词标注

为歌曲歌词添加清晰、直观的演唱提示，方便练习和复习。

* **逐字拆分**：将歌词按字拆分，方便逐字标注。
* **多位置标注**：可在歌词上方、中间或下方添加提示。
* **连唱与停顿提示**：标记连唱、空格停顿等演唱细节。
* **换气标注**：为歌词添加换气提示。
* **音频对照**：配合歌曲音频检查歌词与演唱节奏。
* **自动匹配歌曲文件**：选择音乐文件夹后，可按歌曲名称匹配音频和同名
LRC 歌词。
* **导出与备份**：支持将歌词标注预览导出为 PNG / PDF，并支持 JSON
导入、导出。
* **界面显示**：支持深色与浅色模式，以及标注字号调整。

### 🎵 本地音乐播放器

在同一个应用中管理歌曲并跟随歌词练习。

* **播放列表**：添加歌曲、管理列表，并支持拖拽调整顺序。
* **LRC 歌词**：加载与歌曲对应的 LRC 歌词，并随播放进度逐字高亮。
* **标注歌词播放**：如果标注区中存在同名、带时间戳的歌曲，可以切换显示已保存的标注内容。
* **外观自定义**：可设置背景渐变、纯色或图片，以及歌词颜色和字号。
* **睡眠定时**：设置定时停止播放。
* **便捷导入**：支持拖拽导入音乐和 LRC 歌词。

### 🖥️ 桌面悬浮歌词

* 悬浮歌词使用独立的桌面窗口，不必一直停留在播放器页面。
* 支持透明背景、始终置顶和拖动位置。
* 可调整歌词文字颜色、字号和透明度，以及背景外观。
* 切换到其他软件时，悬浮歌词仍可显示在桌面上。

### 🔗 标注与播放联动

歌词标注与播放器整合在同一个应用中。播放器可以按歌曲名称查找标注区中已导入
LRC、带有时间戳的同名歌曲，并显示其标注内容。

播放时读取的标注内容不会反向修改标注区数据，也不会覆盖播放器原有的 LRC
歌词。

## 下载与安装

1. 打开
[**最新版下载页面**](https://github.com/limo-577/n7m-desktop/releases/latest)。
2. 在 **Assets** 中下载 Windows 安装程序（文件名通常包含 `Setup`
和版本号，并以 `.exe` 结尾）。
3. 双击安装程序，按提示完成安装。
4. 安装后从 Windows 开始菜单或桌面快捷方式启动软件。

普通用户只需要下载安装程序，**不需要另外安装
Node.js，也不需要通过命令行启动软件**。

### 关于 Windows SmartScreen 提示

当前安装程序未使用公开可信的代码签名证书。Windows 首次运行时可能显示
Microsoft Defender SmartScreen
警告。这不等于已经证明程序含有恶意软件，但也不应仅凭这段说明就认定任何下载文件安全。

建议只从本项目的 [GitHub Releases
页面](https://github.com/limo-577/n7m-desktop/releases/latest)
下载，并在发布页提供校验值时核对文件的
SHA-256。若不确定文件来源，请不要运行。

## 数据与隐私

* 歌词标注、播放列表和外观设置保存在应用自己的本地存储空间中。
* 本地标注、播放及 PNG / PDF 导出功能可离线使用。
* 请定期备份重要内容；卸载、清理应用数据或更换电脑时，不要假定本地数据会自动迁移。
* 需要转码或处理音频时，应用使用随程序提供的本地音频组件。

## 适合哪些场景？

* 为外语歌曲歌词添加发音、连唱、停顿或换气提示。
* 练习时逐字查看歌词，并跟随歌曲播放。
* 将整理好的歌词标注导出为图片或 PDF，方便复习与分享。
* 在其他窗口中工作或练习时，让桌面悬浮歌词保持可见。

## 开发者说明

本项目基于 Electron 构建。以下内容仅供开发者使用，普通用户无需操作。

``` powershell
npm ci --ignore-scripts
npm run install:electron
npm test
npm start
npm run dist
```

从源码构建时，请先阅读仓库中的 `package.json`、FFmpeg
相关构建说明与许可文件，并按项目要求准备本地音频组件。不要把开发命令当作普通用户的安装步骤。
